# Cap Table Simulator（資本政策シミュレーター）

CVC / VC 投資家向けの資本政策シミュレーションツール。ラウンド条件を入力すると、
出資後の資本構成（各株主の希薄化後持分）を即時に計算するブラウザ完結型の Web アプリ。

## 機能

- **2つの入力モード**
  - 出資額から取得割合を計算
  - 目標取得割合（ポストマネー基準）から必要出資額を逆算
- **既存株主構成の希薄化計算** — 株主ごとのラウンド前後の持分と増減を一覧表示
- **アップ / ダウンラウンド判定** — 今回プレマネー ÷ 前回ポストマネーの株価倍率
- **オプションプール新設**（ポストマネー基準、既存株主のみを希薄化する実務慣行モデル）
- **株式数・株価の算出**（発行済株式数を入力した場合）
- **感応度分析** — 自社出資額（×0.5〜×1.5）とプレマネー評価額（×0.8〜×1.2）を振ったときの取得割合の変化
- **バリュエーション妥当性の参考指標**（任意入力）
  - 売上マルチプル（プレマネー ÷ 直近売上高）と、参考マルチプルレンジからの逆算プレマネー比較
  - 評価額成長率の年率換算（前回ポスト → 今回プレ、経過月数ベース）
  - 既存株主の希薄化率の一般的レンジ（10〜25%）に対する位置づけ
  - ※ 妥当性の「判断」ではなく判断材料の提供にとどめる設計。コンパラブル分析は対象外
- **Exitマルチプル妥当性評価（VC法 / ターゲット倍率法）**（任意入力）
  - Exit時企業価値 = Exit想定売上 × Exitマルチプル（保守〜強気の2シナリオ）
  - MOIC = Exit企業価値 × 将来希薄化後の残存率 ÷ 今回ポストマネー、IRR = MOIC^(1/年数) − 1
  - 目標リターン倍率から**妥当ポストマネー上限**を逆算し、今回評価額を3段階判定
  - 今回条件で目標達成に必要なExit企業価値（必要マルチプル）も逆算表示
  - ※ 優先分配・清算優先権は考慮しない普通株換算の概算
- **入力情報の3分類バッジ** — CVC担当者向けに情報の入手経路を明示
  - `公開`: 報道・登記・DBなどから自分で調べられる情報
  - `要開示`: 出資検討時にスタートアップから開示を受けるべき情報（タームシート・資本政策表・事業計画）
  - `社内`: 自社（CVC）の投資基準・想定として決める値

## 計算モデル

- ポストマネー = プレマネー + 出資総額
- 新規投資家の持分 = 出資額 ÷ ポストマネー
- 既存株主の希薄化後持分 = 従前持分 × (1 − 新規投資家合計% − プール%)
- 目標取得割合 t からの逆算: 出資額 = t × (プレマネー + 他投資家出資額) ÷ (1 − t)
- 株価 = (プレマネー − プール% × ポストマネー) ÷ 発行済株式数

※ 優先株の残余財産分配・希薄化防止条項・端数調整は考慮しない概算モデル。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | UI（スタイル込み・ダークモード対応） |
| `app.js` | UI ロジック（入力の読み取り・描画） |
| `calc.js` | 計算ロジック（純粋関数・DOM 非依存） |
| `calc.test.mjs` | 単体テスト |

## 起動・テスト

```bash
# ローカル起動（ES Modules のため file:// では動かない）
cd captable-sim && python3 -m http.server 8470

# テスト
cd captable-sim && node --test calc.test.mjs
```
