# 要件定義書: 実地図(Leaflet)表示への移行

## 1. 目的
現状のフィールド探索画面は「現在地からの距離リスト」表示のみであり、視覚的に「歩いて探索している」実感が薄い。
実際の地図(タイル地図)上にプレイヤーやモンスター・アイテムを表示することで、位置情報連動RPGとしての没入感を高める。

## 2. 採用ライブラリ
- **Leaflet** + **react-leaflet**(React向けラッパー)
- タイル地図は **OpenStreetMap** の標準タイルを利用する(無料・APIキー不要)
  - 利用規約上、タイル提供元のクレジット表記が必須

## 3. 機能要件

### 3.1 地図表示
- 画面中央〜上部に地図を表示し、現在地を中心(または現在地に追従)に表示する
- ズームレベルは徒歩での探索に適した範囲(街区が見える程度)に固定 or 限定する
- 地図の出典(© OpenStreetMap contributors)を画面内に表示する

### 3.2 プレイヤー位置の表示
- 現在地に自キャラのアイコン(またはマーカー)を表示する
- 位置情報が更新されるたびに、マーカーの位置をスムーズに追従させる
- 現在地が未取得の間は、取得中であることが分かる表示にする(現状の「位置情報を取得しています…」を地図上/付近に表示)

### 3.3 スポット(モンスター・アイテム)の表示
- `mapSpots` の各スポットを、対応する絶対座標(現状の origin + オフセットのロジックを流用)上にマーカーとして表示する
- マーカーの見た目はモンスター/アイテムで区別できるアイコンにする(例: 👹 / 🎁 のカスタムマーカー、または専用アイコン画像)
- 取得済み・撃破済みのスポットは地図上から消す、またはグレーアウト表示にする

### 3.4 距離・近接判定との連携
- 既存の「近くのスポット」リストは引き続き表示し、地図と併用する(リストをタップすると地図が該当スポットにフォーカスする等は将来検討)
- `ENCOUNTER_RADIUS_METERS` 以内に入ったスポットは、地図上でも視覚的に強調表示する(例: マーカー周囲に円を表示する、色を変える)
- 円表示には Leaflet の `Circle` コンポーネントを使い、半径は `ENCOUNTER_RADIUS_METERS` を指定する

### 3.5 操作性
- 地図はピンチズーム・ドラッグ操作に対応する(Leafletの標準機能)
- 「現在地に戻る」ボタンを設置し、タップすると地図の中心を現在地に戻せるようにする

## 4. 非機能要件
- スマホブラウザ(Safari/Chrome)で滑らかに表示・操作できること
- タイル画像はネットワーク経由で取得するため、オフライン時の表示崩れを許容する(MVP範囲では未対応expectedのフォールバック表示は不要、ただしエラーで画面が壊れないこと)
- 既存の `useGeolocation` フック・距離計算ロジック(`distanceMeters`)はそのまま再利用する

## 5. 影響範囲・変更点
- 対象ファイル: `src/pages/MapExplore.jsx`
- 追加依存パッケージ: `leaflet`, `react-leaflet`
- スタイル: Leaflet の CSS(`leaflet/dist/leaflet.css`)の読み込みが必要
- マーカー画像: デフォルトのLeafletアイコンはバンドル時にパスが崩れる既知の問題があるため、カスタムアイコン設定が必要

## 6. スコープ外(将来検討)
- オフライン地図(タイルキャッシュ)対応
- 3D表示、AR表示
- 複数ワールド(エリア)の切り替えに伴う地図の出し分け
