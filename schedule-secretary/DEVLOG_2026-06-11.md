# 開発レポート（2026-06-11）

## 概要
日程調整AI秘書（schedule-secretary）の構築。Slack DM・Gmail・Googleカレンダーを連携し、自然言語での日程調整依頼に対して空き枠を提案、仮ブロック、確定（カレンダー招待送信）までを自動化。

## 実装した機能

### 1. 基盤・認証
- Node.jsプロジェクト雛形作成
- Google OAuth2認証（Calendar / Gmail）
  - 必要スコープ: `calendar`, `gmail.readonly`, `gmail.send`, `gmail.compose`, `gmail.modify`
- Slack App作成（Socket Mode、Bot Token）

### 2. 毎朝7時のデイリーサマリー
- `node-cron`で毎朝7:00（Asia/Tokyo）にその日のGoogleカレンダー予定をSlack DMへ送信

### 3. Slack DMでの日程調整（自然言語）
- ユーザーがBotにDMで依頼を送ると、Claude APIが意図解析（schedule / confirm / cancel / list / other）
- 空き枠検索（営業時間9-18時、土日除外、複数日に分散して提案）
- 「全候補を仮ブロックして提案」ボタンでカレンダーに仮予定（tentative）登録＋Gmail下書き作成
- 相手の返事をユーザーが報告すると、該当候補を確定（カレンダー招待送信、他の仮ブロックは自動削除）

### 4. Gmail連携（自動検知）
- 5分おきに受信トレイをポーリング
- Claude APIで「日程調整依頼か」を判定
- 依頼であればSlack DMに候補を通知 → 仮ブロック時は元メールのスレッドへ返信下書きを自動作成

### 5. 常駐化
- macOS `launchd`（`~/Library/LaunchAgents/com.scheduleSecretary.plist`）でMac起動時に自動起動・常時稼働

### 6. Git管理
- GitHubリポジトリへコミット・プッシュ（認証情報・APIキーは`.gitignore`で除外）

## 詰まったポイントと解決策

| 詰まった内容 | 原因 | 解決策 |
|---|---|---|
| Google OAuth同意画面で「アクセスがブロックされました」 | テストユーザー未登録 | OAuth同意画面の「テストユーザー」に自分のアカウントを追加 |
| `redirect_uri_mismatch`等は出なかったが、認証コード取得後に`localhost`へリダイレクトされ「接続拒否」エラー | デスクトップアプリ向けOAuthのredirect_uriが`http://localhost`のため、ローカルにサーバーが立っていない | エラーページのURLから`code`パラメータを手動で抽出してCLIに貼り付け |
| Slack「Install to Workspace」で「ボットユーザーがありません」エラー | App Home画面でBot Userの表示名が未設定（空欄） | App Home → App Display Name の「Edit」でBot名を設定後、再インストール成功 |
| Botに個別DMを送れない（チャンネルからの`/schedule`は動作） | App HomeのMessages Tabが無効 | App Home → Show Tabs → Messages Tabを有効化＋「メッセージタブからのメッセージ送信を許可」をON |
| Gmail下書き作成で`Request had insufficient authentication scopes`（1回目） | `gmail.send`スコープのみで`drafts.create`を実行 | `gmail.compose`スコープを追加し再認証 |
| Gmail受信トレイの既読化で再度同じスコープエラー | `messages.modify`（既読化）には`gmail.modify`が必要 | `gmail.modify`スコープを追加し再認証 |
| 提案する候補日程が同日に偏っていた（例: 同じ日の連続した時間枠3つ） | 空き枠探索ロジックが1日分の枠を埋めてから次の日へ進む実装だった | 1日1候補のみ採用し、複数日に分散するようロジック修正。あわせて土日を候補から除外 |

## 現状の構成
- すべてローカル（Mac）で常時稼働、外部公開URLなし
- Slack: Socket Mode（常時接続）
- Gmail/Calendar: OAuth2トークンによるAPI呼び出し
- Claude API: 意図解析・提案文生成
