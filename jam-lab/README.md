# JAM LAB（渋滞研究所）

渋滞のしくみを、マツダ RX-7 (FD3S) で走って学ぶブラウザ完結型の 3D 学習ゲーム。
海沿いの 1 km 周回路を数十台の車列の中で走り、自分のブレーキ 1 回が後ろの車列に何を起こすかを
その場で計測する。「誰も悪くないのに渋滞が生まれる」しくみを、5 つの実験とフリーラボで体験する。

## 概要

- 車列は追従モデル（IDM + 反応遅れ）で動く。プレイヤー車も同じ車列の 1 台
- 各実験は **問い → 操作 → 結果 → 解説** の 4 段で構成。リザルトでは「あなたの 2 秒のブレーキで、後ろの 31 台が減速し、
  合計 412 秒が失われました。波は −18 km/h で後方へ進みました」のように、自分の操作と数字を結びつけて示す
- 星 3 段階の評価と、渋滞学の知見を 1 つずつ紹介する解説カード（一部の実験にはクイズ付き）
- 外部通信なし・ビルド不要・静的ファイルのみ

## 機能

- **5 つの実験 + フリーラボ**
  - 01 小さなブレーキ — 1 台の 2 秒ブレーキが波として後方へ伝わる様子を観察（B キー / ボタンでブレーキ）
  - 02 先を読む運転 — 前方 3 台目の急ブレーキを、車間を使って吸収し、後ろの車を止めない
  - 03 高密度の道路 — 密度が臨界を超えると自然渋滞が生まれる（台数スライダーで再スタート可）
  - 04 反応の遅れ — 反応が遅い車列ほど波が増幅する
  - 05 サグ部 — 下り→上りの谷で無自覚に速度が落ち、渋滞の起点になる
  - FREE — 台数・車間時間・反応の遅れ・希望速度・ばらつき・サグ部をスライダーで自由に変更
- **あなたが起こした波（WAVE IMPACT）** — 影響を受けた後続車、後続車の総時間損失、渋滞波の速度、停止した車、平均速度、交通流率
- **周回路のいま（RING STATUS）** — 周回路ミニマップ。車を速度で色分け（青緑 = 流れている / 橙 = 減速 / 赤 = 停止）
- **観察記録（TIMELINE）** — 車列の平均速度の時系列と、時空間図（縦: あなたから後方の車、横: 時間、色: 速度）
- カメラ 4 種（追従 / 上空 / 全景 / 運転席）、朝 / 夕の切替、一時停止、×1 / ×2 / ×4 倍速
- レベルタブに獲得した星を表示（進捗はブラウザの localStorage に保存）
- レスポンシブ: 1100px 以上は 3 カラム HUD、未満は側面パネルをボトムシートに収納。タッチ端末にはアクセル / ブレーキの大ボタン

## 学べること

- ブレーキ 1 回の減速は、後方へ **波** として伝わり、後ろの車ほど強く減速する（渋滞波は後方へおよそ 15〜20 km/h で進む）
- 車間を空けて走ると、前方の急ブレーキを自分の車間で **吸収** でき、後ろの車を止めずに済む
- 密度が **臨界密度** を超えると、小さな揺らぎだけで渋滞が発生する（自然渋滞）
- **反応の遅れ** が長いほど波は増幅し、止まる車が増える
- **サグ部**（下り→上り）では無自覚に速度が落ち、渋滞の起点になりやすい

## 計算モデル

- 追従モデル: IDM（Treiber 2000）
  `a = a_max · (1 − (v/v0)^4 − (s*/gap)^2)`、`s* = s0 + v·T + v·Δv / (2·√(a_max·b))`
- 反応遅れ τ: 各車は先行車の車間・速度差を τ 秒前の値で見る
- 勾配: `a −= g · grade(s)`（サグ部有効時）。ノイズ: `a += N(0, σ)`
- 数値安定化: a を [−9, +4] m/s² にクランプ、v ≥ 0、衝突は物理的に防ぐ（車は追い越さない）
- 計測
  - 影響を受けた後続車: イベント後に速度が v0 × 0.7 未満に落ちたプレイヤー以外の車の台数（重複なし）
  - 総時間損失: Σ ∫ max(0, 1 − v/v0) dt（秒、プレイヤー以外・イベント後累計）
  - 渋滞波の速度: 各車が初めて v0 × 0.5 未満になった (t, s) の線形回帰（後方へ進むので負）
  - 交通流率: 密度 × 平均速度 × 3.6（台/時）
- ゲームループ: 実時間 dt（上限 0.25 s）× 倍速を 0.05 s のサブステップに分割して積分

| `src/ui/hud.js` | パネルの DOM バインディング・モーダル |

## 起動・テスト

```bash
# ローカル起動（ES Modules のため file:// では動かない）
cd jam-lab && python3 -m http.server 8480
# → http://localhost:8480/

# テスト（sim / shared の純粋モジュールのみ。render / ui はブラウザで確認）
cd jam-lab && node --test tests/*.test.mjs
```
