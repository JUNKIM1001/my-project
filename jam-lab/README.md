# JAM LAB（渋滞研究所）

渋滞のしくみを、マツダ RX-7 (FD3S) で走って学ぶブラウザ完結型の 3D 学習ゲーム。
海沿いの 1 km 周回路を数十台の車列の中で走る。あなたの操作は **ブレーキだけ**。
「何秒踏むと、後ろにどれだけの渋滞が生まれるか」を自分で試して確かめる。

## 概要

- 車列は追従モデル（IDM + 反応遅れ）で動く。プレイヤー車も同じ車列の 1 台で、**常に自動運転**
- あなたができるのは **ブレーキを押している間だけ減速する**こと（強さは -3.0 m/s² 固定）。
  離せば自動で回復するので、操作する変数は「**踏んだ長さ**」だけになる
- **1 回のブレーキ = 1 試行**。離してから 20 秒観察し、その 1 回が生んだ影響を 1 点として記録する
  （観察中は次のブレーキを受け付けない）
- 試行を重ねると「**踏んだ秒数 → 後続の遅れ**」の散布図が育ち、関係を自分で発見できる
- 星 3 段階の評価と、渋滞学の知見を 1 つずつ紹介する解説カード（一部の実験にはクイズ付き）
- 外部通信なし・ビルド不要・静的ファイルのみ

## 機能

- **5 つの実験 + フリーラボ**（すべて「踏む長さ」が軸）
  - 01 はじめの一踏み — 1〜2 秒踏んで、減速が波として後方へ伝わるのを見る
  - 02 長く踏むと、どうなる？ — 短い踏み込みと長い踏み込みを両方試し、差を散布図で比べる
  - 03 混んでいる道路では — 同じ長さでも、台数が増えると影響が跳ね上がる（台数スライダーで比較）
  - 04 反応が遅い車列 — 車列の反応が遅いほど、同じ踏み方でも波が増幅する
  - 05 踏まずに通る — サグ部（下り→上りの谷）を、ブレーキを使わずに越える
  - FREE — 台数・車間時間・反応の遅れ・希望速度・ばらつき・サグ部を自由に変えて何度でも試す
- **ブレーキ計** — 踏んでいる秒数 → 観察中の残り時間 → その 1 回の結果、を中央下に表示
- **あなたが起こした波（WAVE IMPACT）** — 影響を受けた後続車、後続車の総時間損失、渋滞波の速度、停止した車
- **周回路のいま（RING STATUS）** — 周回路ミニマップ。車を速度で色分け（青緑 = 流れている / 橙 = 減速 / 赤 = 停止）
- **観察記録（TIMELINE）** — 平均速度の時系列、時空間図、そして **踏んだ秒数 → 遅れ の散布図**
- カメラ 4 種（追従 / 上空 / 全景 / 運転席）、朝 / 夕の切替、一時停止、×1 / ×2 / ×4 倍速
- レベルタブに獲得した星を表示（進捗はブラウザの localStorage に保存）
- レスポンシブ: 1100px 以上は 3 カラム HUD、未満は側面パネルをボトムシートに収納。
  タッチ端末には画面下に大きなブレーキボタン

## 学べること

- ブレーキ 1 回の減速は、後方へ **波** として伝わる（渋滞波は後方へおよそ 15〜20 km/h で進む）
- **踏んだ長さと渋滞の大きさは比例しない**。このシミュレータでは 48 台の車列で
  1 秒 → 遅れ 13 秒程度、3 秒 → 95 秒程度と、時間 3 倍で損失は 7 倍以上になる
- 同じ長さでも、**混雑しているほど影響が大きい**（72 台では 42 台の 5 倍以上）
- **反応の遅れ** が長い車列ほど波は増幅し、止まる車が増える
- **サグ部**（下り→上り）では無自覚に速度が落ちる。ここで踏むと渋滞の起点になりやすい

## 操作

| 操作 | キー / ボタン |
|---|---|
| ブレーキ（押している間だけ減速） | S / ↓（B も可）。左パネルの「ブレーキ」ボタン、タッチ端末は画面下の大ボタン |
| カメラ切替 | C、または中央下のボタン |
| 一時停止 / 再開 | Space |
| 倍速 | 1 / 2 / 3（×1 / ×2 / ×4） |
| モーダルの主ボタン | Enter |

※ アクセルはない。踏むのをやめれば自動で元の速度に戻る。

## 計算モデル

- 追従モデル: IDM（Treiber 2000）
  `a = a_max · (1 − (v/v0)^4 − (s*/gap)^2)`、`s* = s0 + v·T + v·Δv / (2·√(a_max·b))`
- 反応遅れ τ: 各車は先行車の車間・速度差を τ 秒前の値で見る
- 勾配: `a −= g · grade(s)`（サグ部有効時）。ノイズ: `a += N(0, σ)`
- 数値安定化: a を [−9, +4] m/s² にクランプ、v ≥ 0、衝突は物理的に防ぐ（車は追い越さない）
- 計測
  - 影響を受けた後続車: イベント後に速度が v0 × 0.7 未満に落ちたプレイヤー以外の車の台数（重複なし）
  - 総時間損失: Σ ∫ max(0, 1 − v/v0) dt（秒、プレイヤー以外・イベント後累計）
  - 渋滞波の速度: 各車が初めて v0 × 0.5 未満になった (t, s) の線形回帰（後方へ進むので負）
  - 交通流率: 密度 × 平均速度 × 3.6（台/時）
- ゲームループ: 実時間 dt（上限 0.25 s）× 倍速を 0.05 s のサブステップに分割して積分

## 起動・テスト

```bash
# ローカル起動（ES Modules のため file:// では動かない）
cd jam-lab && python3 -m http.server 8480
# → http://localhost:8480/

# テスト（sim / shared の純粋モジュールのみ。render / ui はブラウザで確認）
cd jam-lab && node --test tests/*.test.mjs
```
