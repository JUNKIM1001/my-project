# 作り替え仕様: 「ブレーキを踏む長さ」を学ぶゲームへ

2026-09-08 のユーザー指示による方針転換。実装前に決めた契約をここに置く（実装後は DESIGN.md へ統合）。

## 変更の要点

1. **アクセルを廃止**。プレイヤーの操作は **ブレーキのみ**。
2. 車は常に **自動運転（IDM）** で走る。ブレーキを押している間だけ、その上に一定の減速
   （`PLAYER_BRAKE_DECEL = 3.0 m/s²`、model.js）を重ねる。離せば自動で回復する。
   → 操作する変数は「**踏んでいた長さ（秒）**」だけ。強さは固定。
3. 1 回のブレーキを **1 試行** として結果を計測し、「踏んだ秒数 → 渋滞の大きさ」を
   散布図に貯めていく。プレイヤーはこの点の並びから関係を自分で発見する。
4. 5 レベルはすべて「踏む長さ」を軸に作り直す。

## 試行（trial）の扱い — game.js が管理

```
ブレーキを押す      → 試行開始。その試行専用の metrics を新規作成し markEvent
押している間        → 経過秒を HUD に大きく表示
離す                → 踏んだ秒数 sec を確定。観察フェーズへ（OBSERVE_SEC = 20 秒）
観察フェーズ        → 次のブレーキは受け付けない（HUD に「観察中 残り n 秒」）
観察終了            → その試行の metrics.summary() を読み、attempts に 1 点追加
```

- 観察中に次のブレーキを禁止するのは、1 回ずつ結果を確かめさせるため（学習上の意図）。
- レベル全体の累積 metrics（`g.metrics`）は従来どおり残し、HUD 右の数値に使う。
  試行用 metrics と両方に `update(sim)` を呼ぶ。

## game.js が levels / hud に渡すもの

```js
// evaluate(level, summary, ctx) に渡る ctx（既存フィールドは維持）
ctx.attempts = [{
  sec,          // 踏んでいた秒数
  affected,     // その試行で影響を受けた後続車 [台]
  timeLoss,     // その試行の後続車の総時間損失 [秒]
  stopped,      // その試行で停止した車 [台]
  waveSpeed,    // その試行の渋滞波速度 [km/h]（null あり）
  carCount,     // その試行時点の台数
  tau,          // その試行時点の反応の遅れ
}]
ctx.brakeCount     // 試行回数 = attempts.length
ctx.totalBrakeSec  // 踏んだ秒数の合計
ctx.longestSec     // 最長の 1 回
ctx.shortestSec    // 最短の 1 回
// 既存: completed, quizCorrect, playerSagMinSpeedRatio, carCount, tau, eventTime,
//       densitiesTried, densityRuns
```

## HUD の新要素（hud.js / charts.js / index.html）

- **ブレーキ計**（中央下、車情報の隣）: 押している間 `0.0 秒` から増える大きな数字。
  離したら `観察中 残り 12 秒`、終わったら結果を 1 行で表示。
- **散布図**（観察記録パネル内、時空間図の隣に追加または切替）:
  横軸 = 踏んだ秒数（0〜6 秒）、縦軸 = 影響を受けた後続車（台）。
  試行のたびに点が増える。直近の点は強調。3 点以上たまったら近似線を引く。
- **アクセル関連の撤去**: `W/↑ アクセル` のキー表示、タッチのアクセルボタン、
  `mode-manual` / `mode-auto` の出し分けをやめ、**大きなブレーキボタン 1 つ**にする。
- キー: `S` / `↓` / `B` / `Space` 以外の空白キーなし（Space は一時停止のまま）。
  マウス / タッチはブレーキボタンを押している間だけ有効。

## レベル設計（levels.js）

すべて `playerMode: 'auto'`（自動運転 + ブレーキ介入）。台本の `leaderBrake` は残してよい。

| # | id | タイトル | 問い | ねらい |
|---|---|---|---|---|
| 01 | first-tap | はじめの一踏み | 1 台のブレーキは、どこまで届く？ | 1 秒ほど踏んで、波が後方へ伝わるのを見る |
| 02 | how-long | 長く踏むと、どうなる？ | 踏む長さで、渋滞はどれだけ変わる？ | 短い(≤1.2 秒)と長い(≥3 秒)を両方試し、散布図で差を見る |
| 03 | crowded | 混んでいる道路では | 同じ 1 秒でも、混雑時は何倍効く？ | 台数を変えて同じ長さを踏み、影響の差を見る |
| 04 | slow-reaction | 反応が遅い車列 | みんなの反応が遅いと、同じ踏み方でも？ | tau 1.5 の車列で同じ長さを踏み、波の増幅を見る |
| 05 | dont-brake | 踏まずに通る | サグ部を、ブレーキを使わずに越えられる？ | 上り坂で我慢する。踏んだ秒数が少ないほど良い |

星の基準（criteria）は各レベルで 3 つ。原則:
- 1 つ目 = 「試した」（attempts が必要数たまった）
- 2 つ目 = 「比べた / 条件を満たした」（長短の差、密度の差など）
- 3 つ目 = 「結果を読み取れた」（クイズ正解、または影響を抑えられた）

FREE（フリーラボ）は台数・反応の遅れ・希望速度・ノイズ・サグを自由に変え、
何度でも踏んで散布図を育てる場とする。星なし・時間無制限。

## 実測した用量反応（2026-09-08、統合前に計測）

48 台・T 1.05・tau 0.65・平衡 12.7 m/s の車列で、一定の -3.0 m/s² を N 秒踏んだときの
「離してから 20 秒間」の後続への影響。

| 踏んだ長さ | 影響台数 | 総時間損失 | 停止した車 | 渋滞波 |
|---|---|---|---|---|
| 0.5 秒 | 0 台 | 3 秒 | 0 | 測定不可 |
| 1.0 秒 | 0 台 | 13 秒 | 0 | 測定不可 |
| 2.0 秒 | 17 台 | 51 秒 | 0 | -16.3 km/h |
| 3.0 秒 | 18 台 | 93 秒 | 0 | -18.0 km/h |
| 5.0 秒 | 20 台 | 180 秒 | 16 | -18.2 km/h |

**判明した重要点: 「影響台数」は 17〜20 台で頭打ちになる。**
これは「速度が 30% 以上落ちた車」という定義上、閾値を超えるか超えないかの二値だから。
一方 **「総時間損失」は 3 → 13 → 51 → 93 → 180 秒と滑らかに増える**。

→ **散布図の縦軸は「総時間損失（秒）」を主とする**（影響台数は副次表示に留める）。
→ **レベルの星判定のしきい値も総時間損失を基準にする**。

参考: 同じ 1 秒でも 72 台（noise 0.25）では損失 55 秒・停止 2 台と、48 台の 13 秒から 4 倍以上に増える。
密度の効果を見せるレベル 03 はこの差を使う。
