# AGENTS.md

このファイルは Codex がレビュー時に参照する指針です。

## Review guidelines（レビュー観点）

差分をレビューする際は、以下を重点的に確認してください。

- **バグ・ロジック誤り**：状態管理の取りこぼし、非同期処理の競合、境界値・null/undefined の未処理。
- **React 固有の注意**：コンポーネント再利用時に props 変更が反映されない問題（key の付け忘れ、初回マウント時しか効かない設定）、useEffect の依存配列漏れ、不要な再レンダリング。
- **セキュリティ**：APIキーやトークンのハードコード、ユーザー入力の未検証、個人情報（参拝者の氏名・位置情報など）のログ出力。
- **入力バリデーション**：フォーム入力・外部データの検証漏れ。
- **可読性・保守性**：明らかに重複したコード、過度に複雑な関数。

## 重大度の付け方

- **P0**：本番が壊れる／セキュリティ事故につながる重大な問題。
- **P1**：機能不全やユーザー体験を大きく損なう問題。
- **P2**：改善が望ましいが致命的でない問題。

## 出力ルール

- 指摘はファイル名・行番号・修正方針をセットで簡潔に。
- 修正すべき指摘が一つもない場合は、最終行に `REVIEW_CLEAN` とだけ出力する。
- 些細な好みの問題で大量の指摘を出さない。重要なものに絞る。
